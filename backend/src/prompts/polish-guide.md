# AI 다듬기 가이드

## 문체 규칙
- 업무 보고에 적합한 간결하고 명확한 문체를 사용한다.
- 경어체(~합니다, ~했습니다)를 기본으로 한다.
- 불필요한 수식어와 중복 표현을 제거한다.

## 구조 규칙
- HTML 태그 구조는 그대로 유지한다.
- 기존 제목(h2, h3)의 계층을 변경하지 않는다.
- 목록(ul, ol) 항목의 순서와 개수를 유지한다.
- "ㄴ"으로 시작하는 항목은 바로 위 항목의 하위 내용이다. 이를 중첩 리스트로 변환한다.
  - 예시 변환 전: `<li>서버 이전</li><li>ㄴ AWS에서 GCP로</li><li>ㄴ 일정 미정</li>`
  - 예시 변환 후: `<li>서버 이전<ul><li>AWS에서 GCP로</li><li>일정 미정</li></ul></li>`
  - "ㄴ" 접두사는 제거하고, 하위 항목들을 상위 `<li>` 안에 `<ul>`로 감싼다.

## 교정 범위
- 맞춤법, 띄어쓰기 오류를 교정한다.
- 어색하거나 모호한 표현을 자연스럽게 수정한다.
- 주어-서술어 호응이 맞지 않는 문장을 바로잡는다.
- 동일한 의미가 반복되는 경우 하나로 통합한다.

## 이전 주 비교 규칙 (이전 주 보고서가 제공된 경우)
- 이전 주와 현재 보고서를 비교하여 각 항목의 진행 상태를 대괄호로 표시한다.
- [진행중]: 이전 주에도 있고 현재도 계속 진행 중인 항목
- [완료]: 이전 주에 있던 항목이 완료된 경우
- [신규]: 이전 주에 없던 새로운 항목
- [보류]: 진행이 멈춘 것으로 보이는 항목
- 진행 상태 태그는 각 항목 텍스트 앞에 굵게(<strong>) 표시한다.

## 이미지 규칙
- 원본에 포함된 `<img>` 태그는 반드시 그대로 보존한다.
- `src` 속성의 URL을 절대 변경하지 않는다.
- 이미지는 관련 항목 근처에 위치시킨다.

## 금지 사항
- 원래 내용의 의미나 핵심 정보를 변경하지 않는다.
- 이전 주 비교 시 진행 상태 태그 외에 새로운 정보를 추가하지 않는다.
- 기존 내용을 삭제하지 않는다.
- `<img>` 태그를 삭제하거나 src를 변경하지 않는다.
- 이모지나 특수문자를 임의로 추가하지 않는다.
